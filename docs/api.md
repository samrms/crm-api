# API Reference

Auth: session cookie

Endpoints:
- POST /auth/register
- POST /auth/login
- GET /auth/me
- POST /auth/password/change
- POST /auth/password/reset/request
- POST /auth/password/reset/confirm
- GET /companies
- POST /companies
- GET /contacts
- POST /contacts
- GET /leads
- POST /leads
- POST /leads/:id/convert
- GET /deals
- POST /deals
- POST /deals/:id/advance
- POST /deals/:id/win
- POST /deals/:id/lose
- POST /exports
- POST /imports
- GET /tasks
- POST /tasks
- GET /health
- GET /ready
- GET /analytics
- GET /docs (Swagger)
